# customer-shopping-analysis
Customer Shopping Analysis – Power BI
📊 Project Overview

This project analyzes the Customer Shopping Dataset using Microsoft Power BI to understand customer purchasing behavior, sales performance, product categories, shopping malls, payment methods, gender, and age groups.

The project contains 14 analytical questions and an interactive dashboard designed to provide meaningful business insights through data visualization.

🎯 Objectives

The main objectives of this project are to:

Identify the top-performing shopping malls.
Analyze revenue generated by different product categories.
Understand monthly sales trends and seasonal patterns.
Compare quantity sold and revenue.
Analyze purchasing behavior by gender.
Identify the highest-revenue age group.
Analyze payment method preferences.
Compare shopping mall performance.
Calculate average purchase value by category.
Compare mall performance across product categories.
Analyze gender distribution across shopping malls.
Study monthly payment trends.
Compare category performance across age groups.
Build an interactive Customer Shopping Dashboard.

📌 Key DAX Measures
Total Revenue
total revenue =
SUMX(
    customer_shopping_data,
    customer_shopping_data[price] *
    customer_shopping_data[quantity]
)
Total Quantity
total quantity =
SUM(customer_shopping_data[quantity])
Total Transactions
total transactions =
DISTINCTCOUNT(customer_shopping_data[invoice_no])
Average Purchase Value
average purchase value =
DIVIDE(
    [total revenue],
    [total transactions]
)
Customer Count
customer count =
DISTINCTCOUNT(customer_shopping_data[customer_id])
